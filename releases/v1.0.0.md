## ✨ 核心功能

- **PDF 页面提取**：按页码或页码范围批量提取页面，生成新的 PDF
  - 起始页 + 结束页双输入，结束页留空 = 只提取该一页
  - 支持多组范围同时提取，自动去重
  - 保留原始页面内容与质量，不重新渲染
- **Excel 批量粘贴**：在 Excel 中复制两列数据（起始页 / 结束页），在「起始页」输入框中长按粘贴批量填入
- **Excel 模板导入**：内置「下载导入模板」，生成带示例和填写说明的 `.xlsx` 模板，编辑后上传自动读取
- **纯本地处理**：不联网、不上传，隐私安全
